# ChainLens · 人形机器人研究台

独立面试作品。围绕人形机器人产业链，连接企业资料、公司公告、公开行业研究、主题ETF和可追溯AI研究样例。深度主故事研究“产品组收入增长能证明什么，距离证明人形机器人业务放量还缺什么”。

当前交付版本humanoid-20：13家企业资料、10家公司iFinD财务（2024/2025共20个年度观察）、7条iFinD公告检索结果，另有本次3批产业业务检索原始记录、6份已收录公司公告、2份公开行业研究摘要、2只主题ETF及独立AI研究入口。业务证据与版本复核闭环仍以3家深度样本为主；财务覆盖不等于已核实供应商或人形收入。本次同步网站、源码、测试文档与连续浏览器操作演示。

交付状态：本地可运行、独立静态部署包；按用户要求不发布至chatgpt.site。产品网址：https://ycm0704.github.io/chainlens-humanoid-research/ 。源码：https://github.com/ycm0704/chainlens-humanoid-research 。源码可通过包内Git镜像独立克隆；源码同步至上述GitHub仓库。最终演示视频为真实浏览器连续操作录制，包含指针、滚动、图表悬停和行展开。

## 目标用户
科技制造行业研究员及有研究基础的个人投资者。核心任务是核查业务与概念关系、判断中外可比边界、追踪条件性传导及修订自己的研究。

## 核心设计
- 图表联动：产业链证据矩阵、公司收入变化条形图、经营坐标散点图、季度对比曲线、收入敏感性矩阵、基金部分持仓环图；悬停解释数值，点击打开业务、原始查询或测算参数。
- iFinD数据台展示实际13批查询（9批财务/公告/行业，3批产业公告，1批基金净值），48条财务观察、10家公司、20个年度观察、7条公告片段。基金净值返回截断序列，隔离未画净值曲线。网页读取取数快照，未实时调用MCP。
- 产业链深化：10个功能环节、13家公司、28项公司×环节产品/业务关系；每个环节有技术路线、经营变量、验证材料与反向条件。视觉与电机分开，灵巧手部件与完整手分开。28项不等于已核实人形供应商关系，其中7项连接基准深度事实，证据缺口与表述记录另列。来源与增量核查、可展开公司证据和AI/对比下一步可直接操作，详见[产业链深化与覆盖](docs/产业链深化与覆盖.md)。
- 自建功能分类：核心零部件→执行与控制→整机与应用。深度证据库3家公司、10个唯一关系（含2个证据缺口）；企业资料目录覆盖13家公司，不把引文数量当覆盖公司或供应关系。
- 同时保留研究节点与披露项目原名。绿的FY2024附注为“谐波减速器及金属部件”；FY2025第37页为“谐波减速器及金属件”。不自行拆出纯减速器或人形应用收入。
- 后台分别保存证据类别、具体阶段、支持方向、复核状态与可并存的有效性标记；A–E只是页面摘要。缺口绑定核查材料、范围、日期及缺项。
- 新增“可比口径透镜”：四组研究入口、13家公司选择、iFinD集团收入趋势/归母净利率/经营现金流率、悬停原值、单季计算明细、可展开年度表格。集团经营、业务范围、人形应用分别展示；无应用拆分时不绘制人形收入图。
- 对比保留报告期起止、币种、产品与合并范围。HDS为2024-04-01至2025-03-31；绿的基准为2024自然年，年度候选为2025自然年。不能对齐则并列展示，不排名、不直接比较PE。
- 海外、政策、供需三种条件性路径，标明假设、推断及待验证边；不伪造已核实的Tesla供应关系。
- 研究保存事实版本、具体关系/字段/期间依赖和待验证假设。相关变化提示复核，原判断不自动失效；支持维持、修订、暂缓并记理由。固定报告期比较不被新年度材料自动判失效。
- 年度观察并存；同年度修订仅替代已声明的同关系、同字段、同期间事实。更正版的存在不证明该收入发生更正；本版未做2025原版与更正版的真实字段对照。
- 恢复版本追加操作并保留后续历史。SHA-256仅检查备份内容一致性，不是签名或独立认证。

## AI角色
独立“AI研究”入口展示业务关联核查、中外可比、量产/成本/政策传导6类研究回放和优必选公告结构化抽取。开发阶段Codex阅读材料，辅助形成结构化候选、研究样例及代码。页面明确离线回放；自由输入是关键词检索与规则整理；查询仅有资料线索的公司时，返回该公司的来源和核查缺口，不用其他公司的财务事实代答。原句存在不等于语义正确，仍需核对公司、应用、期间、范围与结论支持度。

iFinD MCP已在本次开发中实际调用；页面自由问答可检索公司资料并补充关联的iFinD集团财务卡，仍标注“本地证据检索”，不冒称在线模型。可选在线模型适配位于server/app.py，无凭证、无真实调用。本版超时和错误输出仅故障注入测试通过，不宣称线上模型准确率或自动采集。密钥不进入客户端或交付包。

## 数据使用
基准为绿的FY2024年报、HDS截至2025-03财年财务结果、Tesla FY2025 10-K。年度回放来源为绿的FY2025更正后年报（巨潮，2026-07-10），本次入库时间与披露日分开。

只存短摘录、数值、范围、页码与链接，不附完整原始年报。FY2025第37页产品组476,486,798.69元；第185页附注476,486,798.68元的0.01元列示差异被保留为来源冲突。所列数值计算增幅约46.42%，不当作人形收入增幅。扶摇未接入。iFinD真实返回已导入；返回金额中的亿/万保留原始精度，单季图用同年度连续累计值差分，缺值不填零。公告摘要不当原句，行业指标来源与期间冲突已隔离。详见docs/iFinD接入与验证.md。

扩展来源记录于dist/catalog.mjs：新增公司官网产品与业务介绍、优必选采购合同公告、三花历史募集说明书、Morgan Stanley公开研究摘要、IFR工业机器人统计摘要，以及基金公司官方资料。基金穿透仅展示2025-06-30华夏机器人ETF前十名中与本库匹配的2项，非全量持仓或实时资金流；BOTZ持仓未导入。详见docs/研究范围扩展与AI入口核查.md。

## 已知边界
- iFinD工具在开发会话内可调用；静态网页读取已导入的真实结果。重载按钮只重读快照，不发起新查询。未部署MCP桥接服务，不承诺离线或公开页面自动访问用户授权的数据源。
- 10家公司财务为接口观察值，未逐项核对原年报；公告7条为片段/摘要，不是7份独立已复核公告。未获取日本证券接口，HDS等仍用公开资料。数据提供方权限与网页公开分发权限须在未来发布前分别核对，本轮仅本地使用。
- 公共基准文件对所有访问者相同；操作历史和研究仅存在当前网址、当前浏览器的localStorage，刷新保留。不同浏览器、设备、网址不共享，清理数据会丢失。
- 证据操作与研究台账分别备份恢复，包含事实、出处、时间、复核与版本；不含原年报全文、密码或密钥。同名研究恢复拒绝覆盖。不同域名迁移需先备份。
- 复核人是操作者自填署名，未经账户身份认证；开发验证署名不是实际研究员审核。
- 人形收入未拆分不等于零；未获取客户身份不等于公司不存在该客户。缺口检索范围不是全公告穷尽搜索。
- 本版最多100条证据操作、50项研究；每项保留最近10次研究修订。证据操作在限额内不删除历史。假设为显式保存的待验证条件，未实现自动因果识别。

## 运行与部署
需Python3.10+；前端无依赖、无需构建。macOS双击“启动研究台.command”，Windows运行“启动研究台.bat”；若系统拦截脚本，请按部署说明手动运行。浏览器打开http://127.0.0.1:8765/，这是本地地址，不能作为评审公网链接。

```sh
python3 server/app.py
node --test tests/*.test.mjs
node scripts/import_ifind.mjs data/ifind/2026-10-28
python3 -m unittest discover -s tests -p 'test_*.py' -v
node scripts/evaluate_retrieval.mjs
```

部署完整dist文件夹即可得到公网URL；不要只上传index.html。主源码带Vercel和Netlify静态配置；纯静态托管不运行Python在线AI适配。详细操作见“部署说明.md”。

离线仓库：git clone ChainLens-review.bundle chainlens。镜像排除视频及截图以保持轻量；媒体另附于交付包。
