# ChainLens · 人形机器人研究台

独立面试作品。研究“产品组收入增长能证明什么，距离证明人形机器人业务放量还缺什么”。

交付状态：本地可运行、独立静态部署包；按用户要求不发布至chatgpt.site。尚无新的公网URL。源码可通过包内Git镜像独立克隆；未声称已推送GitHub。演示视频96秒，为真实操作截图编排，非连续录屏。

## 目标用户
科技制造行业研究员及有研究基础的个人投资者。核心任务是核查业务与概念关系、判断中外可比边界、追踪条件性传导及修订自己的研究。

## 核心设计
- 自建功能分类：核心零部件→执行与控制→整机与应用。首版3家公司、10个唯一关系（含2个证据缺口），不把引文数量当覆盖公司或供应关系。
- 同时保留研究节点与披露项目原名。绿的FY2024附注为“谐波减速器及金属部件”；FY2025第37页为“谐波减速器及金属件”。不自行拆出纯减速器或人形应用收入。
- 后台分别保存证据类别、具体阶段、支持方向、复核状态与可并存的有效性标记；A–E只是页面摘要。缺口绑定核查材料、范围、日期及缺项。
- 对比保留报告期起止、币种、产品与合并范围。HDS为2024-04-01至2025-03-31；绿的基准为2024自然年，年度候选为2025自然年。不能对齐则并列展示，不排名、不直接比较PE。
- 海外、政策、供需三种条件性路径，标明假设、推断及待验证边；不伪造已核实的Tesla供应关系。
- 研究保存事实版本、具体关系/字段/期间依赖和待验证假设。相关变化提示复核，原判断不自动失效；支持维持、修订、暂缓并记理由。固定报告期比较不被新年度材料自动判失效。
- 年度观察并存；同年度修订仅替代已声明的同关系、同字段、同期间事实。更正版的存在不证明该收入发生更正；本版未做2025原版与更正版的真实字段对照。
- 恢复版本追加操作并保留后续历史。SHA-256仅检查备份内容一致性，不是签名或独立认证。

## AI角色
开发阶段Codex阅读材料，辅助形成结构化候选、研究样例及代码。页面明确离线回放；自由输入是关键词检索与规则整理。原句存在不等于语义正确，仍需核对公司、应用、期间、范围与结论支持度。

可选在线模型适配位于server/app.py，无凭证、无真实调用。本版超时和错误输出仅故障注入测试通过，不宣称线上模型准确率或自动采集。密钥不进入客户端或交付包。

## 数据使用
基准为绿的FY2024年报、HDS截至2025-03财年财务结果、Tesla FY2025 10-K。年度回放来源为绿的FY2025更正后年报（巨潮，2026-07-10），本次入库时间与披露日分开。

只存短摘录、数值、范围、页码与链接，不附完整原始年报。FY2025第37页产品组476,486,798.69元；第185页附注476,486,798.68元的0.01元列示差异被保留为来源冲突。所列数值计算增幅约46.42%，不当作人形收入增幅。扶摇/iFinD未接入。详见数据与口径、覆盖清单。

## 已知边界
- 公共基准文件对所有访问者相同；操作历史和研究仅存在当前网址、当前浏览器的localStorage，刷新保留。不同浏览器、设备、网址不共享，清理数据会丢失。
- 证据操作与研究台账分别备份恢复，包含事实、出处、时间、复核与版本；不含原年报全文、密码或密钥。同名研究恢复拒绝覆盖。不同域名迁移需先备份。
- 复核人是操作者自填署名，未经账户身份认证；开发验证署名不是实际研究员审核。
- 人形收入未拆分不等于零；未获取客户身份不等于公司不存在该客户。缺口检索范围不是全公告穷尽搜索。
- 本版最多100条证据操作、50项研究；每项保留最近10次研究修订。证据操作在限额内不删除历史。假设为显式保存的待验证条件，未实现自动因果识别。

## 运行与部署
需Python3.10+；前端无依赖、无需构建。macOS双击“启动研究台.command”，Windows运行“启动研究台.bat”；若系统拦截脚本，请按部署说明手动运行。浏览器打开http://127.0.0.1:8765/，这是本地地址，不能作为评审公网链接。

```sh
python3 server/app.py
node --test tests/*.test.mjs
python3 -m unittest discover -s tests -p 'test_*.py' -v
node scripts/evaluate_retrieval.mjs
```

部署完整dist文件夹即可得到公网URL；不要只上传index.html。主源码带Vercel和Netlify静态配置；纯静态托管不运行Python在线AI适配。详细操作见“部署说明.md”。

离线仓库：git clone ChainLens-review.bundle chainlens。镜像排除视频及截图以保持轻量；媒体另附于交付包。
