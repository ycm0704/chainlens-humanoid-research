## 产品亮点：可比口径透镜

“集团经营—业务范围—人形应用”切换用于检查自己究竟在比较什么。集团财务不能转名为人形业务收入；在人形应用层尚未取得拆分时，显示核查缺口，不复用集团曲线。

收入趋势采用各自2025 Q1=100，展示自身经营变化；归母净利率=单季归母净利润/同季集团收入，现金流率=单季经营现金流/同季集团收入。它们不构成业务纯度、供应关系、盈利质量评级或估值排名。HDS报告期2024-04-01—2025-03-31与自然年错位；无连续数据时留空，只保留原币种披露。

悬停显示期间、指数或比率、近似单季收入；点击季度展开原始累计输入与差分公式；年度明细展开后进入来源、公司业务或公告。图表仅连接真实季度观察，不拟造月度波动。

## 数据质量处理

1. **返回精度**：如5.7071亿，是接口缩写值，换算为元只是近似值。保留raw、value、quantum、approximate，不补造元以下精度。绿的年度官方570714025.26元与接口值之差在其返回步长的一半以内，不认定为业务或报告更正。
2. **累计与单季**：单独的季度查询返回参数统一标“第一季度”，与多季结果不一致，因此该批单季字段未进入图表。图表仅采用年度批次中明确的累计字段，通过同年相邻期间差分获得单季值；缺少任一累计输入就留空，跨年不差分，计算继承输入精度。
3. **币种**：优必选港股财报返回人民币，因此为CNY；Tesla为USD。交易货币不替代报表货币，未做汇率换算。
4. **公告片段**：5条绿的结果、2条拓普结果中包含生成式摘要、重复报告片段和截断表格；当前工具未返回原文链接。它们不是7份独立法定公告，不作为已确认关系或原文引句。原有原文证据保持独立。
5. **行业指标隔离**：请求国家统计局工业机器人当月同比S005566712，返回元数据却为产业在线、截至2026-08，数据表包含2026-09。来源和期间不一致，原始返回保留，整条序列隔离，不画图、不作为人形出货。
6. **版本**：年度接口观察与原有年报版本并存，不自动替换任何关系事实或已保存研究，不默认“更正后年报”意味着收入更正。入库时间独立于披露日。

## 可复现更新与存储

原始记录：`data/ifind/2026-10-28/*.json`，包含format、provider、tool、request、response、capturedAt；不含账户密码、模型密钥或MCP认证配置。capturedAt为本次返回结果保存时间，不声称是上游发布时间或最初调用的精确起点。

```sh
node scripts/import_ifind.mjs data/ifind/2026-10-28
```

脚本校验数字、证券、币种、期间、来源引用和结果结构，生成dist/ifind-snapshot.json。原始返回以内容SHA-256保存在dist/ifind/raw/；规范化快照在data/ifind/versions/按内容摘要保留，再原子替换当前文件。相同输入可复现相同内容版本；失败的财务候选不发布部分替换，保留原有文件。哈希用于完整性核对，不是独立真实性认证。

这条命令**不执行联网采集**。MCP连接属于当前开发会话；浏览器不能自动调用会话工具。重新查询需由已获授权的MCP采集端输出同格式新批次，再导入。页面“重载本地快照”只是读取当前已导入文件。网页直连MCP、后台定时调度及共享云端数据服务均为计划实现，当前不宣称完成。

快照文件对同一本地服务的访问者相同；用户研究、关注和证据操作仍存当前浏览器localStorage，不被财务导入覆盖。快照重载失败时，本次已载入快照留在内存且显示错误；首次加载失败则保留公开披露研究入口，不虚构iFinD数字。跨设备和跨浏览器仍不共享个人记录。
